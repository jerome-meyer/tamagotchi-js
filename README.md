# Tamagotchi JS 🐾

Jeu interactif inspiré des animaux virtuels Tamagotchi des années 90, entièrement développé en JavaScript.

## ✨ Fonctionnalités
- Jauges de statut en temps réel : Faim, Énergie, Bonheur, Propreté
- Actions interactives : Nourrir, Jouer, Dormir, Laver
- Animations et séquences vidéos réactives selon l'état de l'animal
- Conditions d'évolution et fin de partie

## 🛠️ Technologies
- **HTML5** (éléments audio et vidéo)
- **CSS3**
- **JavaScript** vanilla

## 🚀 Utilisation
Ouvrez `index.html` dans votre navigateur.
